# MeshCentral-FileDistribution-Fork

Раздача файлов из раздела **My Files** на конечные устройства.

Это форк [meshcentral-community/MeshCentral-FileDistribution](https://github.com/meshcentral-community/MeshCentral-FileDistribution),
**созданный для личного использования**. Он публикуется как есть, без каких-либо
гарантий и без обязательств по поддержке. Если он пригодится кому-то ещё — хорошо,
но он не задумывался как замена оригиналу для широкого круга пользователей.

Репозиторий сообщества, в свою очередь, является форком
[ryanblenis/MeshCentral-FileDistribution](https://github.com/ryanblenis/MeshCentral-FileDistribution)
и существует ради сохранения кода, а не его развития: собственных изменений в нём нет.
Поэтому проблемы оригинала, не обновлявшегося с 2021 года, в нём остались —
в частности, плагин не работает в современной теме MeshCentral.

Автор исходной работы — Ryan Blenis.

## Что изменено

**Работает в современной теме.** Оригинал показывал диалоги через
`parent.setDialogMode()` — в `default3.handlebars` эта функция вызывается без
ошибок, но окно не отображает, поэтому кнопка `[+]` выглядела мёртвой. Форк
рисует свои модальные окна внутри собственного iframe и не зависит от
внутренностей темы.

**Закрыта дыра в правах.** В оригинале `serveraction` не проверял ничего:
любой аутентифицированный пользователь мог отправить сообщение вручную и
раздать произвольный файл с сервера на произвольное устройство, включая те,
которых он не видит. Теперь каждое действие проверяет права на конкретный узел.

Полный список правок — в [changelog.md](changelog.md).

## Установка

Плагины должны быть включены в `meshcentral-data/config.json`:

```json
"plugins": { "enabled": true }
```

Затем **My Server → Plugins → Download plugin** и адрес манифеста:

```
https://raw.githubusercontent.com/Avtomax88/MeshCentral-FileDistribution-Fork/main/config.json
```

`shortName` остался `filedist`, а коллекция в базе — `plugin_filedistribution`,
поэтому существующие раздачи сохранятся при переходе с оригинала или с версии
сообщества. Ставить два из них одновременно нельзя: они займут одну папку и одну
коллекцию в базе.

После установки **обновите ядра агентов** — плагин добавляет модуль в meshcore.

## Как это работает

Файлы раздаются с сервера в выбранный путь на выбранном устройстве. Агент
проверяет свои файлы каждые 20 минут: если файла нет или его размер не
совпадает, он запрашивает файл с сервера. Сервер тоже раз в 20 минут проверяет
исходные файлы в My Files и рассылает изменившиеся тем агентам, что сейчас
онлайн; офлайновые получат обновление при подключении.

При удалении раздачи можно выбрать, удалить ли файл с устройства. По умолчанию
файл остаётся на месте и просто перестаёт обновляться. Удаление доходит только
до устройств, которые сейчас онлайн: офлайновое сохранит файл, но саму раздачу
забудет при следующем подключении.

Удаляется ровно один файл по пути, взятому из базы, — браузер путь не передаёт,
подставить его нельзя. Перед удалением агент сверяет размер файла с тем, что
был роздан: если файл на устройстве заменили или изменили, он остаётся на
месте. Причина отказа пишется в отладочный лог агента.

## Массовая раздача

Страница **My Server → Plugins → File Distribution** позволяет раздать файл
сразу на несколько устройств и показывает все существующие раздачи.

Устройства отбираются фильтрами по состоянию (все, онлайн, офлайн), по группам
и поиском по имени. Кнопки «выбрать показанные» и «снять показанные» действуют
на текущий результат фильтрации, так что можно набирать выборку по частям.

Список устройств берётся из интерфейса, но решение принимает сервер: права на
каждый узел проверяются заново перед записью, недоступные узлы пропускаются
молча. Повторная раздача того же файла в тот же путь дубликат не создаёт.

Массовые операции выполняются пачками по 10 узлов, чтобы не подвешивать сервер.
Ограничение — 1000 устройств за раз.

Вкладка на странице устройства остаётся для точечной работы с одной машиной.

## Кто что может

| Действие | Требуется |
|---|---|
| Видеть список раздач устройства | права управления этим устройством |
| Добавить или удалить раздачу | права управления этим устройством |

Под правами управления понимается `MESHRIGHT_MANAGECOMPUTERS` на группе
устройств (или на самом устройстве), либо полные права сайт-администратора.
Проверка намеренно строгая: всё, что не удалось подтвердить, отклоняется.
Если в вашей схеме нужны другие права, правьте `userCanManageNode`
в `filedist.js`.

## Известные ограничения

Часть из них унаследована от оригинала и не исправлена в этой версии.

- **Файлы сверяются по размеру, а не по хешу**, поскольку в MeshAgent нет
  удобного хеширования. Изменение файла без изменения размера не будет
  замечено. Обходится включением версии в имя файла.
- **Передача неэффективна**: файл читается в hex и каждый чанк уходит
  отдельным JSON-сообщением по websocket агента. Это удваивает объём и не
  имеет контроля потока — большие файлы стоит раздавать осторожно.
- **Проверка владения исходным файлом не реализована.** Путь проверяется на
  выход за пределы папки файлов, но не на то, что этот файл принадлежит именно
  этому пользователю. Практический риск ограничен тем, что раздавать файлы
  могут только пользователи с правами управления устройствами.
- Конфигурации нет: интервал в 20 минут задан в коде.
